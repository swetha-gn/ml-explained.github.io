  <section class="wg-panel">
    <p class="wg-eyebrow">Community roadmap</p>
    <h1>Use GitHub Pages for the website. Add community features through connected services.</h1>
    <p class="wg-lede">
      GitHub Pages is the right home for a fast portfolio and blog. Because it is static hosting,
      user accounts, user posts, moderation queues, and databases should live in a separate discussion
      tool or backend when the site grows.
    </p>
  </section>

  <section class="wg-panel">
    <p class="wg-eyebrow">Recommended rollout</p>
    <h2>Three phases instead of overbuilding on day one</h2>
    <div class="wg-roadmap">
      <article class="wg-card wg-card--accent">
        <p class="wg-card__meta">Phase 1</p>
        <h3>Publish consistently</h3>
        <p>Use Markdown posts for explainers, paper notes, project logs, and learning summaries.</p>
      </article>
      <article class="wg-card">
        <p class="wg-card__meta">Phase 2</p>
        <h3>Add comments and discussions</h3>
        <p>Enable GitHub Discussions and connect Giscus so every post can have a lightweight conversation thread.</p>
      </article>
      <article class="wg-card">
        <p class="wg-card__meta">Phase 3</p>
        <h3>Move to a full forum if needed</h3>
        <p>Use Discourse, Supabase, Firebase, or a custom backend when readers need profiles and independent posts.</p>
      </article>
    </div>
  </section>
